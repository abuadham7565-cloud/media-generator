    توثيق API — للمطورين

    واجهة عامة بدون تسجيل دخول وبدون مفاتيح — CORS مفتوح، الأخطاء بصيغة {"error":"..."}، والروابط المطلقة تُبنى من دومين الطلب نفسه.

    الطريقةالمسارالوظيفة
    POST/api/jobsإنشاء مهمة دمج (روابط و/أو ملفات)
    GET/api/jobsقائمة مختصرة بأحدث المهام
    POST/api/upload?job=&seq=&chunk=رفع أجزاء الملفات (ثنائي ≤4MB)
    POST/api/jobs/<id>/processتنفيذ الدمج كاملًا → رابط الفيديو النهائي
    GET/api/jobs/<id>الحالة + التقدم (0–100) + الرابط عند الاكتمال
    GET/api/jobs/<id>/videoبث الناتج بدعم Range و?download=1 للتحميل
    DELETE/api/jobs/<id>حذف فوري شامل للمهمة وأجزائها
    GET/api/configالحدود العامة + version
    GET/api/cronحذف المهام المنتهية (Cron يومي)
    1) إنشاء مهمة من روابط
    2) إنشاء مهمة بمصادر مختلطة (رابط + ملف سيُرفع)
    3) رفع جزء ملف (4MB كحد أقصى — كرّر مع chunk=1,2,…)
    4) تنفيذ الدمج (متزامن — يرجع رابط الفيديو النهائي)
    5) متابعة الحالة والتقدم
    6) تحميل الناتج (أو مشاهدته مباشرة بدون download=1)
    7) حذف المهمة نهائيًا
    8) استعلام الحدود العامة
